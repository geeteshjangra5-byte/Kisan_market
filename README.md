The application will have four primary types of users:

Customer — Browse products, add items to cart, place orders, make payments, and track orders.
Farmer / Seller — Add and manage products, maintain stock, and manage customer orders.
Delivery Partner — Manage assigned deliveries and update delivery status.
Admin — Manage users, farmers, products, orders, and the overall platform.
